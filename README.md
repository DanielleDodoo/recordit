# recordit (phone)

recordit's phone web app: record a conversation, tap **Highlight** or **Note** at the moments that matter, then
**Send to laptop**. The laptop's recordit transcribes it offline and places your highlights and notes on the
right passages. Recordings stay on your phone and your own devices; this repository holds code only.

Open https://danielledodoo.github.io/recordit/ on the phone and add it to the home screen.
